# حاسبة مساحة البيفوت (PivotCalc)

تطبيق ويب لحساب **مساحة كل عجلة** في نظام الري المحوري (Center Pivot)، مع دعم العمل **أوفلاين** وبدون إعلانات.

---

## المميزات

- حساب نصف القطر من مساحة البيفوت (بالفدان)
- اختيار ماركة البيفوت (Valley / Zimmatic / Western) أو إدخال مخصص
- حساب عدد الجور لكل عجلة تلقائياً
- جدول يوضح مساحة كل عجلة بدقة رقمين عشريين
- تعبئة تلقائية أو إدخال يدوي لعدد الجور
- دعم اللغة العربية والإنجليزية
- الوضع الليلي / النهاري
- يعمل أوفلاين بعد أول فتح (PWA)
- بدون إعلانات نهائياً

---

## طريقة الاستخدام

1. أدخل **مساحة البيفوت** بالفدان
2. اختر **الماركة** أو استخدم الوضع المخصص
3. حدد **عرض الجرة** (بالمتر)
4. اضغط **تعبئة تلقائية** لملء الجدول
5. يمكنك تعديل عدد الجور يدوياً وسيتم إعادة حساب المساحات

---

## المعادلة المستخدمة

المساحة محسوبة حسب معادلة المساحات الحلقية:

\[
A_n = \frac{\pi \times (r_n^2 - r_{n-1}^2)}{4200}
\]

حيث:
- \( r_n \) = نصف القطر حتى العجلة رقم n (بالمتر)
- \( 4200 \) = تحويل المتر المربع إلى فدان (تقريبي)

العجلة الأخيرة تُعدَّل تلقائياً لتتوافق مع المساحة الكلية للبيفوت.

## التثبيت كـ PWA

1. افتح الموقع في المتصفح (Chrome / Edge / Safari)
2. اضغط على زر **تثبيت** الذي يظهر في الأعلى
3. أو من قائمة المتصفح → "إضافة إلى الشاشة الرئيسية"

بعد التثبيت يعمل التطبيق مثل التطبيقات العادية حتى بدون إنترنت.
